# Сервис бота

Telegram-бот для управления получателями и отправки голосовых поручений через inline-кнопки.
SQLite-схема находится в `database/schema.sql`.

## Настройка

Рекомендуется Python 3.10+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .\bot-service\.env.example .\bot-service\.env
```

Укажите `BOT_TOKEN` в `bot-service/.env`, затем запустите бота:

```powershell
python .\bot-service\Application.py
```

Рабочая база данных создается автоматически в `bot-service/database/bot.sqlite3`.

ML-настройки:

- `SLOT_FILLING_MODEL_PATH` - путь к финальной папке модели slot filling, по умолчанию `../ml-service/models/rubert-slot-filling`.
- `STT_MODEL_SIZE` - размер модели faster-whisper, по умолчанию `base`.
- `STT_DEVICE` - устройство для распознавания, по умолчанию `cpu`.

## Архитектура

- `Application.py` запускает polling aiogram и собирает зависимости.
- `config.py` читает `.env` и переменные окружения.
- `handlers/` содержит обработчики inline-действий.
- `repositories/` содержит доступ к SQLite и модели данных.
- `services/` содержит бизнес-логику бота и временные состояния диалогов.
- `database/schema.sql` содержит схему SQLite.
- `../ml-service/ml_service/` содержит локальные ML-сервисы: STT, slot filling и сопоставление получателей.
- `../ml-service/train_slot_filling.py` запускает обучение slot filling модели.

## Интерфейс

Основной интерфейс работает через inline-кнопки в чате.

Доступные действия:

- добавить получателя по `chat_id` и ФИО;
- посмотреть список получателей;
- отправить голосовое сообщение с автоматическим определением получателя;
- удалить получателя;
- посмотреть `user_id`, `chat_id` и тип чата;
- открыть справку.

Для добавления получателя нажмите `Добавить получателя`, затем отправьте одним сообщением `chat_id` и ФИО получателя.
Логика добавления текущего чата не используется.

Для отправки сообщения нажмите `Отправить`, затем отправьте голосовое сообщение. В голосовом нужно назвать получателя
и текст, например:

```text
Передай Алану Султангарееву, что он молодец
```

Бот распознает голос, выделит получателя и текст через slot filling, сопоставит имя с вашими получателями из БД,
при низкой уверенности предложит выбрать получателя кнопкой, затем покажет сообщение на подтверждение перед отправкой.
Получателю сообщение приходит в формате `отправитель: текст`.
