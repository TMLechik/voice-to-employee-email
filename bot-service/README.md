# Сервис бота

Telegram-бот для управления клиентами, получателями сообщений и связями между ними.
Схема SQLite адаптирована из `database/init.db`, где хранится исходный SQL проекта.

## Настройка

Рекомендуется Python 3.10+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .\bot-service\.env.example .\bot-service\.env
```

Укажите `BOT_TOKEN` в `bot-service/.env`, затем запустите бота:

```powershell
python .\bot-service\Application.py
```

Рабочая база данных создается автоматически в `bot-service/database/bot.sqlite3`.

## Архитектура

- `Application.py` запускает polling aiogram и собирает зависимости.
- `config.py` читает `.env` и переменные окружения.
- `handlers/` содержит обработчики команд, разделенные по командам.
- `repositories/` содержит доступ к SQLite и модели данных.
- `services/` содержит бизнес-логику бота.
- `database/schema.sql` содержит схему SQLite.

## Интерфейс

Основной интерфейс бота работает через inline-кнопки в чате.
Команда `/start` открывает главное меню, где доступны действия:

- добавить текущий чат как получателя;
- посмотреть список получателей;
- выбрать получателя и отправить ему сообщение;
- удалить получателя из списка;
- посмотреть `user_id`, `chat_id` и тип чата;
- открыть справку.

Для отправки сообщения нажмите `Отправить`, выберите получателя кнопкой, затем отправьте текст следующим сообщением.

## Быстрые команды

Кнопки являются основным способом работы, но команды оставлены как быстрые алиасы:

- `/start` открывает главное меню.
- `/help` показывает справку.
- `/id` показывает текущие `user_id` и `chat_id`.
- `/add_recipient` привязывает текущий чат как получателя.
- `/add_recipient <chat_id> <name>` привязывает внешний чат по ID.
- `/recipients` показывает список привязанных получателей.
- `/remove_recipient <number|chat_id|@username>` удаляет связь с получателем.
- `/send <number|chat_id|@username|all> <text>` отправляет текстовое сообщение.
